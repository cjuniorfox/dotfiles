# Kernel

## Reinstall Kernel Longterm

```shell
sudo dnf reinstall kernel-longterm-core kernel-longterm kernel-longterm-modules kernel-longterm-modules-extra grub2-efi-x64 shim-x64 grub2-tools grub2-tools-extra
```

## Reinstall Kernel

```shell
sudo dnf reinstall kernel-core kernel kernel-modules kernel-modules-extra grub2-efi-x64 shim-x64 grub2-tools grub2-tools-extra
```
